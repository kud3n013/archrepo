📦 archrepo

Automated Arch Linux package repository hosted on GitHub.

Installation

Add the repository to /etc/pacman.conf:

[archrepo]
SigLevel = Optional TrustAll
Server = https://github.com/kud3n013/archrepo/releases/download/packages

Then synchronize package databases:

sudo pacman -Syy

Available Packages

  • proton-mail-bin - Proton Mail official desktop client
  • proton-pass-bin - Proton Pass official desktop application
  • zalo-for-linux-bin - Zalo for Linux (with Wayland support)
  • beeper-bin - Beeper unified messenger (formerly Beeper v4)
  • freedownloadmanager-bin - Free Download Manager (Qt6 with Wayland/X11 support)
  • freedownloadmanager-elephant-bin - Free Download Manager Elephant add-on (powered by yt-dlp)
  • howdy-next-bin - Howdy Next: facial-recognition authentication for Linux (patched, no OpenCV WARN spam)
