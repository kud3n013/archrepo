📦 archrepo

Automated Arch Linux package repository hosted on GitHub.

Installation

Add the repository to /etc/pacman.conf:

[archrepo]
SigLevel = Optional TrustAll
Server = https://github.com/kud3n013/archrepo/releases/download/packages

Then synchronize package databases:

sudo pacman -Syy

Available Packages

  • zalo-for-linux - Zalo for Linux (with Wayland support)
  • beeper - Beeper unified messenger (formerly Beeper v4)
  • antigravity - Google Antigravity 2.0 multi-agent orchestration platform
  • freedownloadmanager-elephant - Free Download Manager Elephant add-on (powered by yt-dlp)
  • howdy-next - Howdy Next: facial-recognition authentication for Linux (patched, no OpenCV WARN spam)
  • zotero-better-bibtex - Better BibTeX for Zotero (LaTeX bibliography & citation management)
  • zotmoov - ZotMoov (automated attachment file mover and linker for Zotero)
  • zotero-better-notes - Better Notes for Zotero (comprehensive note management)
  • zotero-ocr - Zotero OCR (Optical Character Recognition for PDFs via tesseract/poppler)
  • zotero-pdf-translate - Translate for Zotero (PDF, EPUB, and note translation with 20+ services)
  • zotero-mcp - Zotero Model Context Protocol (MCP) server & standalone CLI
