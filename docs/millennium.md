### Overview
Millennium hooks into the Steam Client on Linux to provide real-time skinning, CSS modifications, JavaScript plugins, and community theme support without modifying core Steam binaries.

### Packaging Details
- Packaged directly from upstream pre-compiled release.
- Installs shared bootstrap libraries to `/usr/lib/millennium/`.
- Includes an install scriptlet that guides setup and permissions.
