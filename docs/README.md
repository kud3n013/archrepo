## 🛠️ Flag System & Custom Configuration

Many GUI applications in `archrepo` ship with an intelligent flags loader:
- System defaults are located in `/etc/<package>-flags.conf`
- User overrides can be placed in `~/.config/<package>-flags.conf`
- Settings take effect on the next application launch without editing `.desktop` files or root permissions.
