### Overview
Better BibTeX (BBT) is an indispensable extension for Zotero users working with LaTeX, Overleaf, Org-mode, or Pandoc. It provides predictable, customizable citation keys and automated background export.

### Packaging Details
- Packaged as a system-wide extension into `/usr/lib/zotero/distribution/extensions/`.
- Automatically activates for all users running `zotero`.
